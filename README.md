One word, first thought — no topic, no explanation, no second draft. This entry sends a single word to the judge: **nudiustertian**.

## The word

**nudiustertian** — *relating to the day before yesterday.*

Why this word, of all words? Because it does what the competition rewards: it surprises. Everyone has lived the day before yesterday, yet almost nobody knows there is a single word for it. It is rare without being noise, pronounceable once you sound it out (noo-dee-us-TUR-shun), and it carries a small joke inside it: a dusty Latin mouthful for the most ordinary day there is. A judge weighing surprise, vividness, and a spark of wit should find all three here — a word that makes the reader stop and think, "there is a word for that?"


## How it works

`main.py` holds the word as one constant, validates that it is exactly one word (non-empty, no whitespace, at most 200 characters), and writes it — byte for byte, no trailing newline, no extra text — to `/output/entry.txt`. The run is fully deterministic: the same word every time, no randomness, no clock, no network, Python standard library only.

## Run it

```sh
python3 main.py
```

Then `/output/entry.txt` holds exactly:

```text
nudiustertian
```
